Chapter One

The Origin Story

How a kid with a sketchbook became the city’s layout league.

Issue Zero

Grew up in Hyderabad tracing newspaper strips and stealing the Sunday color pages. Learned that a thick black line can hold a whole world together.

The Bite

A late-night HTML class went sideways. One broken layout later, I was hooked — grids felt like panel gutters, type like sound effects.

The Creed

I design like a penciler and ship like an inker. Every site gets a cover, a splash page, and a last-panel punchline. No muddy midtones. No limp hierarchy. If it does not read at arm’s length, it goes back to the board.
