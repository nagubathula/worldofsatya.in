# KIRA VOLT — Comic Book Portfolio

A single-page portfolio styled like a Silver Age comic: newsprint paper, Ben-Day dots, thick ink frames, speech balloons, and splash titles.

Open `index.html` in a browser. No build step.

## Swap in your story

- Name and alias: `index.html` cover section (`KIRA` / `VOLT`)
- Stats, origin copy, powers, missions, quotes, contact
- Art in `assets/images/`
  - `cover.jpg` — hero splash
  - `portrait.jpg` — origin portrait
  - `mission-*.jpg` — case studies

## Type

Google Fonts: Bangers, Bungee, Comic Neue, Oswald.

## Colors

Defined in `css/style.css` as `--ink`, `--paper`, `--red`, `--yellow`, `--blue`.
